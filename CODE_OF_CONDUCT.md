# Code of Conduct

## Our commitment

We are committed to a welcoming, safe, and productive community for people of every background, identity, experience level, and perspective.

## Expected behavior

Community members should:

- Communicate with empathy, patience, and technical honesty.
- Critique ideas and code rather than people.
- Respect privacy, confidentiality, and organizational security boundaries.
- Accept constructive feedback and correct mistakes openly.
- Give appropriate credit and respect licenses and intellectual property.
- Help keep discussions focused and accessible.

## Unacceptable behavior

The following are not tolerated:

- Harassment, discrimination, threats, stalking, or sexualized attention.
- Personal attacks, insults, intimidation, or sustained disruption.
- Publishing another person's private information without permission.
- Sharing credentials, private source code, exploit details, or confidential organizational data without authorization.
- Deliberately misleading security reports, fabricated evidence, spam, or abusive automation.
- Retaliation against someone who raises a good-faith concern.

## Scope

This code applies in repository issues, pull requests, discussions, reviews, release channels, and other spaces where someone represents the project.

## Enforcement

Report conduct concerns privately to the maintainers through the repository's private vulnerability-reporting channel when confidentiality is needed. For non-sensitive concerns, use a repository issue marked for maintainer attention without repeating harmful content.

Maintainers may edit or remove content, issue warnings, temporarily restrict participation, or permanently ban participation. Decisions should be proportionate, documented privately when appropriate, and made without retaliation.
